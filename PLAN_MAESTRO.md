# PLAN MAESTRO: Curso Profesional Completo de Matemáticas Avanzadas
## GitHub Pages + GitHub Actions - Desde Cero hasta Nivel Universitario Avanzado

---

## 🎯 VISIÓN GENERAL

**Objetivo**: Crear el curso de matemáticas más completo, intuitivo y didáctico del mundo en formato web, accesible para alguien con **cero experiencia e incluso repulsión** a las matemáticas, llevándolo hasta nivel universitario avanzado.

**Stack Tecnológico**:
- **HTML5 semántico** + **CSS3 moderno** (CSS Grid, Flexbox, Custom Properties, Container Queries)
- **Vanilla JavaScript ES2024** (módulos, Web Components, IntersectionObserver, IndexedDB)
- **KaTeX** para renderizado LaTeX ultra-rápido
- **Chart.js / D3.js** para gráficas interactivas
- **GitHub Actions** para build + deploy automático a GitHub Pages
- **IndexedDB** para progreso offline-first + sincronización
- **Web Components** para elementos reutilizables (tarjetas, tooltips, gráficas, certificados)

**Principios Pedagógicos Core**:
1. **Andamiaje progresivo** (Zone of Proximal Development - Vygotsky)
2. **Carga cognitiva gestionada** (Sweller) - un concepto a la vez
3. **Aprendizaje activo** - cada pantalla requiere interacción
4. **Retroalimentación inmediata** - explicación *antes* de siguiente pregunta
5. **Gamificación significativa** - rachas, logros, certificados con valor real
6. **Dual Coding** (Paivio) - texto + visual + interactivo simultáneo
7. **Espaciado y entrelazado** - repaso espaciado automático (algoritmo SM-2)

## 📚 ESTRUCTURA CURRICULAR (Basado en Pensum MIT, Harvard, Stanford, Oxford, ETH Zurich, Cambridge, IIT, UNAM, UBA)

### FASE 0: FUNDAMENTOS PRE-MATEMÁTICOS (Semanas 1-2)
*Diseñado para quien "odia" las matemáticas - elimina ansiedad, construye intuición*

| Módulo | Temas | Objetivo Pedagógico |
|--------|-------|---------------------|
| 0.1 | **¿Qué es un número?** (conteo, cardinalidad, ordinalidad) | Subitizing, correspondencia 1-1, principio de abstracción |
| 0.2 | **Sentido numérico** (estimación, magnitud, recta numérica) | Número como posición y cantidad, benchmarking mental |
| 0.3 | **Operaciones como acciones** (unir, separar, comparar, repartir) | Modelos semánticos: parte-todo, cambio, comparación, agrupamiento |
| 0.4 | **Patrones y regularidades** (secuencias, periodicidad, simetría) | Pensamiento algebraico temprano, generalización |
| 0.5 | **Lenguaje matemático** (símbolos, convenciones, precisión) | Desmitificar notación, "leer" matemáticas como idioma |

### FASE 1: ARITMÉTICA Y PRE-ÁLGEBRA (Semanas 3-8)

| Módulo | Temas Principales | Subtemas Clave |
|--------|-------------------|----------------|
| 1.1 | **Números Naturales** | Propiedades, divisibilidad, mcd/mcm, factorización prima, teorema fundamental |
| 1.2 | **Enteros** | Recta numérica extendida, valor absoluto, operaciones con signos, elevación a potencias enteras |
| 1.3 | **Racionales** | Fracciones (modelos: área, recta, conjunto), decimales exactos/periódicos, conversión, porcentaje, razón, proporción |
| 1.4 | **Reales** | Irracionales (√2, π, e), densidad, intervalos, notación científica, órdenes de magnitud |
| 1.5 | **Potenciación y Radicación** | Leyes de exponentes (enteros, racionales), notación radical, racionalización, jerarquía de operaciones |
| 1.6 | **Álgebra Elemental** | Variable, expresión, término, polinomio, operaciones, factorización común, productos notables, ecuaciones lineales |
| 1.7 | **Sistemas de Ecuaciones** | 2×2, 3×3 (sustitución, igualación, reducción, Cramer, Gauss), interpretación gráfica, problemas de aplicación |
| 1.8 | **Inecuaciones** | Lineales, cuadráticas, con valor absoluto, sistemas, región factible |

### FASE 2: FUNCIONES Y ÁLGEBRA AVANZADA (Semanas 9-16)

| Módulo | Temas Principales | Subtemas Clave |
|--------|-------------------|----------------|
| 2.1 | **Concepto de Función** | Dominio, codominio, imagen, gráfica, inyectividad, suprayectividad, biyectividad, composición, inversa |
| 2.2 | **Funciones Elementales** | Lineal, cuadrática, polinómica, racional, raíz, valor absoluto, parte entera, signo |
| 2.3 | **Transformaciones Gráficas** | Traslaciones, dilataciones, reflexiones, parámetros a,b,h,k en f(x)=a·f(b(x-h))+k |
| 2.4 | **Función Exponencial y Logarítmica** | Definición, propiedades, base e, logaritmo natural, ecuaciones, modelo de crecimiento/decay, interés compuesto |
| 2.5 | **Funciones Trigonométricas** | Círculo unitario, sen, cos, tan, cot, sec, csc, identidades fundamentales, gráficas, período, amplitud, fase |
| 2.6 | **Trigonometría Avanzada** | Fórmulas de adición, doble/medio ángulo, suma-producto, ecuaciones trigonométricas, triángulos oblicuangulos (leyes senos/cosenos) |
| 2.7 | **Números Complejos** | Forma binomica/polar/exponencial, operaciones, raíz n-ésima, teorema de Moivre, ecuaciones polinómicas, plano de Argand |
| 2.8 | **Polinomios Avanzados** | Teorema del resto, factor, raíces racionales, regla de Descartes, límites, comportamiento asintótico |
| 2.9 | **Sucesiones y Series** | Aritmética, geométrica, recursivas, límite, convergencia, serie telescopica, serie armónica, criterios de convergencia |

### FASE 3: GEOMETRÍA Y TRIGONOMETRÍA ANALÍTICA (Semanas 17-22)

| Módulo | Temas Principales | Subtemas Clave |
|--------|-------------------|----------------|
| 3.1 | **Geometría Euclidiana Plana** | Puntos, rectas, ángulos, triángulos (congruencia, semejanza, centros notables), cuadriláteros, circunferencia, teoremas clásicos |
| 3.2 | **Geometría Analítica** | Coordenadas cartesianas, distancia, punto medio, pendiente, ecuaciones de la recta, posición relativa, haz de rectas |
| 3.3 | **Cónicas** | Circunferencia, parábola, elipse, hipérbola: ecuaciones canónicas/grales, elementos, tangentes, propiedades ópticas, ecuación general de 2º grado |
| 3.4 | **Geometría del Espacio** | Vectores en R³, producto escalar/vectorial/mixtos, rectas y planos, distancias, ángulos, tetraedros, esferas |
| 3.5 | **Transformaciones Geométricas** | Isometrías, homotecias, afinidades, matriz de transformación, valores propios/vectores propios geométricos |

### FASE 4: CÁLCULO DIFERENCIAL E INTEGRAL (Semanas 23-34)

| Módulo | Temas Principales | Subtemas Clave |
|--------|-------------------|----------------|
| 4.1 | **Límites y Continuidad** | Definición ε-δ, límites laterales, infinitos, indeterminaciones, teoremas, continuidad, Teorema de Bolzano, Weierstrass, Darboux |
| 4.2 | **Derivada** | Definición como límite, interpretación geométrica/física, reglas (suma, producto, cociente, cadena), derivadas implícitas, paramétricas, orden superior |
| 4.3 | **Aplicaciones de la Derivada** | Razones de cambio, optimización, Teorema del Valor Medio (Rolle, Lagrange, Cauchy), regla de L'Hôpital, concavidad, puntos de inflexión, asíntotas, croquizado |
| 4.4 | **Integral Indefinida** | Antiderivada, integración inmediata, sustitución, partes, fracciones parciales, sustitución trigonométrica, integrales de funciones racionales/irracionales/trigonométricas |
| 4.5 | **Integral Definida** | Suma de Riemann, Teorema Fundamental del Cálculo (Barrow), propiedades, cambio de variable, funciones definidas por integrales |
| 4.6 | **Aplicaciones de la Integral** | Área entre curvas, volúmenes (discos, washers, capas cilíndricas), longitud de arco, área de superficie de revolución, trabajo, centro de masa, teorema de Pappus |
| 4.7 | **Ecuaciones Diferenciales** | Separables, lineales de 1er orden, exactas, homogéneas, Bernoulli, 2º orden lineales cte, aplicaciones (crecimiento poblacional, enfriamiento, circuitos RL/RC) |
| 4.8 | **Cálculo Multivariable (Intro)** | Funciones de varias variables, límites, derivadas parciales, diferencial total, cadena, gradiente, direccional, extremos condicionados (Lagrange), integrales dobles/triples |

### FASE 5: ÁLGEBRA LINEAL Y MATEMÁTICAS DISCRETAS (Semanas 35-42)

| Módulo | Temas Principales | Subtemas Clave |
|--------|-------------------|----------------|
| 5.1 | **Matrices y Determinantes** | Operaciones, inversa, rango, determinante (propiedades, Laplace, Sarrus, Gauss), regla de Cramer, teorema de Rouché-Frobenius |
| 5.2 | **Espacios Vectoriales** | Definición, subespacios, generadores, dependencia/independencia lineal, base, dimensión, coordenadas, cambio de base |
| 5.3 | **Transformaciones Lineales** | Núcleo, imagen, teorema de la dimensión, matriz asociada, autovalores, autovectores, diagonalización, forma canónica de Jordan |
| 5.4 | **Producto Interior** | Espacios euclídeos, ortogonalidad, proceso Gram-Schmidt, proyección ortogonal, mínimos cuadrados, descomposición QR, SVD |
| 5.5 | **Matemáticas Discretas** | Lógica proposicional/predicados, demostración (directa, contrapositiva, contradicción, inducción fuerte/estructural), teoría de grafos básica, combinatoria, recurrencias |

### FASE 6: TEMAS AVANZADOS Y APLICACIONES (Semanas 43-52)

| Módulo | Temas Principales | Subtemas Clave |
|--------|-------------------|----------------|
| 6.1 | **Análisis Real Avanzado** | Sucesiones de funciones, convergencia uniforme, series de potencias, series de Fourier, transformada de Laplace |
| 6.2 | **Análisis Complejo** | Funciones holomorfas, Cauchy-Riemann, integral de Cauchy, serie de Laurent, residuos, aplicaciones a integrales reales |
| 6.3 | **Ecuaciones Diferenciales Parciales** | Clasificación, separación de variables, ecuación del calor, onda, Laplace, series de Fourier en PDEs |
| 6.4 | **Probabilidad y Estadística Matemática** | Espacios de probabilidad, variables aleatorias, distribuciones (discretas/continuas), límite central, estimación, contraste, regresión |
| 6.5 | **Optimización y Investigación de Operaciones** | Programación lineal (Simplex, dualidad), convexa, KKT, programación entera, redes, colas, decisión |

## 🧩 COMPONENTES WEB CORE (Especificación)

### 1. `<math-formula>` - Renderizado LaTeX Inteligente
```html
<math-formula 
  latex="\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}"
  display="block"
  hover-explain="true"
  click-to-copy="true"
  animate-on-scroll="true">
</math-formula>
```
**Features**: KaTeX SSR + hidratación, tooltip por símbolo (data-math-tooltip), copia LaTeX/ MathML, animación de "escritura" al hacer scroll, modo inline/block, error boundary visual.

### 2. `<hover-tooltip>` - Explicaciones Contextuales
```html
<hover-tooltip 
  target="math-formula, .concept-term"
  position="auto"
  delay="150"
  interactive="true">
  <template slot="content">
    <h4 slot="title">Término</h4>
    <p slot="definition">Definición clara...</p>
    <math-formula slot="formula" latex="..."></math-formula>
    <a slot="link" href="#modulo-relacionado">Ver más</a>
  </template>
</hover-tooltip>
```
**Features**: Posicionamiento inteligente (Floating UI), contenido rico (HTML + LaTeX), navegable por teclado, persistente si `interactive`, delay de entrada/salida configurable.

### 3. `<interactive-graph>` - Gráficas Pedagógicas
```html
<interactive-graph 
  type="function|parametric|polar|vector-field|3d|statistics"
  data='{"functions":[{"expr":"sin(x)","color":"var(--brand-primary)","label":"sen(x)"}],"range":[-2*PI,2*PI]}'
  sliders='[{"var":"a","min":-2,"max":2,"step":0.1,"default":1,"label":"Amplitud"}]'
  points="draggable"
  tangent="true"
  derivative="toggle"
  integral="toggle"
  export="png|svg|csv">
</interactive-graph>
```
**Features**: Chart.js 2D / Three.js 3D, sliders reactivos vinculados a variables LaTeX, puntos arrastrables que actualizan fórmulas, tangentes/derivadas/integrales visuales, exportación, modo "exploración guiada" con hitos.

### 4. `<quiz-card>` - Motor de Preguntas Adaptativo
```html
<quiz-card 
  mode="learning|assessment|spaced-review"
  question-id="mod2.3-q14"
  difficulty="adaptive"
  hints="progressive"
  explanation="required"
  xp="10">
  <template slot="question">
    <p>Si $f(x) = 2x^2 - 3x + 1$, ¿cuál es $f'(2)$?</p>
  </template>
  <template slot="options" type="multiple-choice">
    <option correct="true" value="5">5</option>
    <option value="1">1</option>
    <option value="7">7</option>
    <option value="9">9</option>
  </template>
  <template slot="hint-1">Recuerda la regla de la potencia: $(x^n)' = n x^{n-1}$</template>
  <template slot="hint-2">Deriva término a término: $(2x^2)' - (3x)' + (1)'$</template>
  <template slot="explanation">
    <p>Aplicamos la regla de la potencia...</p>
    <math-formula latex="f'(x) = 4x - 3"></math-formula>
```

**Features**: 7 tipos de pregunta (MC, multi-select, input numérico, input LaTeX, drag-drop matching, ordering, graph-sketch), hints progresivos, explicación obligatoria tras responder, algoritmo SM-2 para repaso espaciado, dificultad adaptativa (IRT simplificado), XP y rachas.

```yaml
# .github/workflows/deploy.yml
name: Build & Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:
  schedule:
    - cron: '0 3 * * 0'  # Weekly rebuild for fresh certificates

concurrency:
  group: pages
  cancel-in-progress: true

      - name: Setup Node

      - name: Install dependencies

      - name: Validate content

      - name: Run tests
        run: npm run test
        
      - name: Build production
        run: npm run build
        env:
          BUILD_DATE: ${{ github.event.head_commit.timestamp }}

      - name: Generate sitemap

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
```
